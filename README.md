# 乱码文件名修复台（MojibakeFixer）

> **跨平台压缩包与旧系统乱码文件名批量逆向诊断、置信度评分与安全事务回滚工具**  
> 一套 100% 本机离线运行的文件名字符编码观测与修复仪器。

---

## 它是什么

在跨操作系统（如 Windows、Linux、macOS）解压 Zip、通过旧邮件客户端传输或从非 UTF-8 数据库导出文件时，常因解码器误判编码造成严重乱码。本工具基于确定性字符编码映射与逆向流水线实现安全修复：

- **6 条经典误判逆向流水线**：
  - `UTF8_AS_GBK`：UTF-8 字节被误当 GBK 解读（典型：`鍏ㄦ爤鏋舵瀯` → `全栈架构`）；
  - `GBK_AS_LATIN1`：GBK 字节被误当 Latin-1 解读（典型：`²âÊÔ` → `测试`）；
  - `UTF8_AS_LATIN1`：UTF-8 字节被误当 Latin-1 解读（典型：`æ–‡ä»¶` → `文件`）；
  - `GBK_AS_BIG5`：繁简平台交叉误判；
  - `SHIFT_JIS_AS_GBK`：日文字节误判；
  - `URL_PERCENT_ENCODED`：百分号编码转义残留；
- **中文可读性评分器（0~100 分）**：基于 GB2312 常用汉字覆盖率、ASCII 合法字符与 CJK 生僻区伪汉字惩罚计算置信度；
- **原本正常文件保护**：自动识别正常文件名，绝不盲目破坏；
- **安全重命名事务机制**：改名前强制生成事务备份 JSON，随时支持 100% 一键原样撤回。

---

## 它不是什么

- **它不是模糊猜测玩具**：严禁硬编码静态词典映射，所有还原均基于字节流二次重编码的真实数学与编码表；
- **它不是云端修复服务**：100% 本机离线运行，绝不上传任何文件名或文件内容；
- **它不是暴力重命名脚本**：具备冲突检测与原子级回滚保障，防止数据丢失。
